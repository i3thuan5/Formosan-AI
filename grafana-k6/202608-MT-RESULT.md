# MT 延遲測試報告：更新前後比較（2026-08-15）

族語基礎翻譯系統（mt，NLLB-600M）線上服務於 2026-08-15 更新，本報告比較更新前後的延遲表現。

測試方法與測試資料的完整規格見 [METHOD.md](METHOD.md)；本報告只摘錄與本次比較相關的部份。

## 測試方式

| 項目 | 內容 |
| --- | --- |

| 執行方式 | `vus=1`、`iterations=100`（單一 VU 連續執行 100 次，測無競爭情況下的延遲，非壓力測試） |

| 更新前執行時間 | 2026-08-15 04:25 UTC |
| 更新後執行時間 | 2026-08-15 06:16 UTC |
| 原始檔 | `results/mt-summary.2026-08-15-before.json`、`results/mt-summary.json` |
| 失敗率／checks | 兩次皆為 0%／100% |

> 若要確認品質沒有退步，需要另外用完整的測試集跑 BLEU／chrF 之類的指標，那不在本延遲測試的範圍內。

## 結論

mt 這次更新讓延遲降到原本的約 1/7，且：

- 改善涵蓋兩個翻譯方向、所有測試句，非局部性效果。
- 尾端延遲（p95／p99）改善幅度比平均更大，回應時間也更穩定（全距、p99/中位數比值都大幅縮小）。
- 4 句抽查下翻譯輸出未變，初步看不是靠犧牲品質換取速度，但仍建議另外跑完整品質測試集確認。
